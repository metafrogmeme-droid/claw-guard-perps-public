## Lessons and follow-ups
- A paused host stops every timer at once, so in-process timeouts cannot catch it. Idea: compare wall clock with the monotonic clock each cycle; on a jump over N s, mark "host paused" and go straight to close-out with that reason.
- status.json should show "stale" when its heartbeat stops (an outside check reads its age).
- Run sessions fully detached (setsid + nohup) so the starting worker going away cannot end them.
- Post-only exits can sit unfilled for many cycles. Idea: after K cycles of a repeated exit signal, switch to a reduce-only IOC inside the guard limits.
- If doctor reads margin 0 or link false while a session is open, retry the read before acting on it.
